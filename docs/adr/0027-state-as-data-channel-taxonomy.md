# ADR-0027：状态即数据与通道分类学 —— 算子是面，数据流是一等公民

- **状态**：已接受（状态通道原语 + 恢复协议已落地，EXACT MATCH 验证通过）
- **日期**：2026-08-31
- **决策者**：Pride Leong
- **关联**：[adr/0024](./0024-dsl-op-primitive.md) · [adr/0025](./0025-from-component-reference.md) · [adr/0026](./0026-slice-input-model.md) · [adr/0020](./0020-message-reflection-monitor.md)

## 背景

三个相互关联的建模判断（2026-08-31 评审提出）：

1. **算子是面不是点**：处理器/算子/组件/函数既消费也生产数据，是流上的面状节点（N 入 M 出、面到面/块到面的处理逻辑），不是点到点的函数。通道（有名/匿名）只是整个系统数据流中的分类管道。
2. **有状态计算的可追溯困境**：状态通常是算子内部变量，血缘不可见。逻辑上可从历史分区数据重放还原（精确但计算/延迟大）——**或者，状态本身发布进数据流**：状态就有了版本、有了血缘。
3. **通道的两类本质**：有名 = 完全解耦模块间的接口契约（apollo 式，可复用组件，形成领域接口规范）；匿名 = 耦合/临时连接（适配器、前/后处理），逻辑分层解耦、代码耦合。

## 决策

### 1. 状态即数据（state channels）

**状态发布的合法性**：算子可声明状态通道，把内部状态的每次更新作为消息发布。状态与普通数据在数据流中无本质区别——都是带版本、带血缘的一等公民。

**两种模式（对写放大的诚实分层）**：

| 模式 | 语义 | 适用 |
|---|---|---|
| 连续发布 | 每次更新即一版，版本精确 | 小状态、高频关键量（车速、滤波器状态） |
| 快照发布 | 每 N 次/每间隔发布一版，版本粗粒度 | 大状态、高频更新（占据栅格、地图切片） |

**四个收益**：版本（checkpoint）、血缘（`state#k = 输入血缘 + hop`，branch 模型承接）、可恢复（见下）、可观测（ti-monitor 直接看状态通道，状态调试不用打断点）。

**与历史重放的对偶性**：状态 = 输入历史的 fold。发布状态 = 增量物化视图（便宜、有版本）；历史重放 = 按需重算（精确、昂贵）。二者不是二选一——**恢复 = 取 state#k + 重放后缀**，正是对偶的结合使用。

**与 ADR-0025/0026 的组合（可重构数据流）**：

```
恢复协议：取最新 state#k
  → 其血缘（区间跳）指出已吸收输入到哪条（ADR-0026）
  → 只重放其后缀输入（同步派生携带父血缘，ADR-0025 修正）
  → 状态重建，血缘连续
```

**设计张力（记录在案）**：写放大（连续 vs 快照两档缓解）；大状态（不能整块发布的 → 地址式存储 + 版本元数据，SHM 演进项）；非确定源（真实传感器不可重放——重放路径只对 record 基底成立）。

**默认匿名**：状态通道默认匿名（内部细节），除非状态本身是跨模块契约（如底盘状态）。

### 2. 通道分类学：契约 vs 接线

| | 有名通道 | 匿名通道 |
|---|---|---|
| 本质 | **接口契约** | **结构接线** |
| 适合 | 完全解耦的独立模块、可复用组件、领域接口（"雷达→点云"、"规划→轨迹"） | 适配器、前/后处理、图内部中间形态 |
| 稳定性 | 语义稳定，跨模块依赖 | 随图演化，无人外部依赖 |
| 与 schema（ADR-0020） | 通道契约 = 名字 + 类型 + schema + 语义约定 | 不需要 |

**关键推论（L1 编译器的优化法律基础）**：

- **匿名性 = 可优化边界**：编译器可融合/内联匿名通道两侧的算子（无外部依赖），如 kernel fusion
- **有名性 = 契约边界**：语义承诺所在，编译器不得改变其存在性/顺序/类型

与编译器对内部符号 vs 导出符号的处理同构。v0 的自动匿名通道（`~N`）由此获得设计正当性：不只是"用户没起名"，而是**声明了这段接线不构成契约**。

### 3. 算子是面（原则表述，承接既有决策）

N 入 M 出的面状节点形态已由 ADR-0024 多端口演进锁定（每路输出类型化 `OpPub`、链元组返回）；本 ADR 将其上升为原则表述：**原语 = 面状节点，通道 = 分类管道，点到点只是最简退化**。点消费/点输出（map）与切片输入（ADR-0026）分别是输入/输出维度的退化与一般化。

## 影响范围

- 落地情况（2026-08-31）：`builder.stateful<TOut, TState>` 原语 + 恢复协议（checkpoint 血缘定吸收点 + 后缀重放）已实现，`state_recovery_demo` EXACT MATCH 验证；跨进程（kill -9 + SHM）为后续
- 通道分类学进入 L1 编译器设计前提（融合边界规则）
- ADR-0020 的 schema 机制成为有名通道契约的组成部分

## 风险与缓解

| 风险 | 缓解 |
|---|---|
| 状态通道写放大 | 连续/快照两档；状态通道可标记为非热路径消费者 |
| 大状态不可整块发布 | 地址式存储 + 版本元数据（SHM 演进项，接 ADR-0010 ShmPool） |
| 状态通道被外部依赖（破坏匿名初衷） | 默认匿名 + 分类学规则：命名即承诺契约 |
| 重放确定性 | 算子须确定性（同一输入切片 → 同一输出）；非确定算子显式标注不可恢复 |
